# 阅卷台

一个可直接部署的静态首版在线试卷批改网站。支持试卷分类、创建分类、上传图片或 PDF、教师队列、画笔/橡皮擦/撤回/恢复、评语、分数和结果查看。

## 本地预览

直接用浏览器打开 `index.html`，或使用任意静态服务器。

## 免费部署（Vercel）

1. 将本目录上传到 GitHub 仓库。
2. 在 [Vercel](https://vercel.com) 用 GitHub 账号登录，点击 **Add New → Project** 并导入仓库。
3. 框架预设选择 **Other**，不需要构建命令，点击 **Deploy**。

部署后的网址即为可访问的网站。

## 云端持久化说明

当前首版为零配置演示：数据和图片保存在当前浏览器的 `localStorage`，无需后端即可完整体验流程。若要让不同用户/设备共享试卷，按 `supabase.sql` 创建免费 Supabase 项目并将应用接入其数据库和 Storage。
